# 莲花麻将游戏规则整理

> 来源：`D:\PycharmProjects\mahjong_server\subgame\LianhuaMahjongGame.py`，并依据其直接调用的 `Rule.py`、`MahjongGame.py` 和 `main.py` 补全胡牌与流程规则。
>
> 本文描述的是该文件中的旧版莲花麻将实现，尤其是 `JingGame`。它与本项目当前后端的“红中花牌、白板固定癞子”规则并不相同：旧版采用**掷骰翻精，翻出牌及其下一张均为癞子**。

## 1. 基本牌制与座位

- 4 人游戏，使用 136 张牌：万、筒、索各 1～9，东、南、西、北、中、发、白各 4 张；不含花牌。
- 每位玩家起始分数为 2000；基础结算单位为 `B = 100`。
- 玩家以 `0～3` 编号；`dealer_idx` 表示庄家编号。
- 庄家先拿 14 张牌并先出牌，闲家各拿 13 张。
- 上一局有人胡则由胡牌者坐庄；流局则原庄家继续坐庄。

## 2. 翻精与牌墙

将 136 张牌组成 68 墩，每墩上下各 1 张。牌墙按四家分段，每家 17 墩：

| 逻辑座位 | 对应位置   |
| ----- | ------ |
| 0～16  | 庄家前方   |
| 17～33 | 庄家下家前方 |
| 34～50 | 庄家对家前方 |
| 51～67 | 庄家上家前方 |

3D 牌桌的物理环序从庄家前方开始，依次为：庄家 `0～16`、上家 `17～33`、对家
`34～50`、下家 `51～67`。因此逻辑座位 `0/1/2/3` 映射到物理墙段起点
`0/51/34/17`；这只影响翻精牌在桌面上的位置，不改变按座位逆时针数玩家的规则。

### 第一次掷骰：确定翻精位置

1. 掷两枚骰子，点数和为 `S`。
2. 翻精所在方位为 `(dealer_idx + S - 1) % 4`，即从庄家开始按点数顺推决定目标方位。
3. 从目标方位牌墙的右侧数第 `S` 墩，翻开该墩**上层**牌。
4. 翻开的牌从牌墙移除，不会再被摸到。

因此，翻精并非总在庄家位置；只有骰子和使目标方位回到庄家时才会在庄家牌墙翻精。

### 精牌（癞子）

本局有两种精牌，均可作为万能牌参与胡牌：

1. 翻开的指示牌本身；
2. 同类牌序中的下一张。

“下一张”按以下规则循环：

| 翻出类型  | 下一张规则     |
| ----- | --------- |
| 万、筒、索 | 1→2→…→9→1 |
| 风牌    | 东→南→西→北→东 |
| 箭牌    | 中→发→白→中   |

精牌可以打出，也可以作为吃、碰、杠。但是这种情况精牌只能作为普通牌使用。

白板除了本身的属性，还能代替精牌本身原来的牌（比如翻出来的精是7p，则白板可以当7p、8p、白板使用）。

### 第二次掷骰：确定开门位置

第二次掷骰，由第一次点数确定的目标方位玩家开始掷骰（非庄家投掷）

1. 再掷两枚骰子，点数和为 `T`。
2. 从翻精所在墩顺时针向后数 `T+1` 墩，作为发牌及正常摸牌的起点（若摸到精牌位置，精排跳过不摸）。
3. 牌墙尾端用于开杠后的补牌（若到精牌位置，精排跳过不摸）。

### 发牌

- 从庄家起依序发牌；每轮每人取 2 墩（4 张），共 3 轮。
- 庄家随后连续取 2 张作为“跳牌”，得到 14 张。
- 三位闲家再各补 1 张，得到 13 张。

## 3. 胡牌牌型

胡牌必须满足总张数 `3n + 2`。代码支持以下基础牌型：

| 牌型          | 基础番数 | 实现条件                                                                              |
| ----------- | ---: | --------------------------------------------------------------------------------- |
| 平胡          |  1 番 | 面子与将牌组成；精牌可补缺牌                                                                    |
| 七对子         |  2 番 | 必须为 14 张；精牌可与单张配对，余下精牌须两两成对。不计平胡                                                  |
| 十三烂         |  2 番 | 必须门前清、直接检查实际 14 张手牌；精牌可替代牌面，且任一花色中相邻点数至少相差 3。不要求特定数量的字牌。不计平胡                 |
| 七星十三烂       |  4 番 | 必须门前清、且包含东南西北中发白七字、所有牌均不重复，且任一花色中相邻点数至少相差 3。七字允许精牌替补，不要求物理齐全。不计十三烂、平胡                                |
| 十三幺         |  8 番 | 必须门前清 东风、南风、西风、北风、红中、绿发、白板、一万、九万、一条、九条、一饼、九饼这13张牌手中都要有，且其中要有一对才能和牌。允许精牌替补，不要求物理齐全。不计十三烂、七星十三烂、平胡 |
| 天胡、地胡       |  8 番 | 不计自摸、庄家、平胡。                                                                       |
| 自摸、抢杠胡、杠上开花 |   ×2 | 抢杠胡与杠上开花加计自摸和庄家                                                                   |
| 庄           |   ×2 | 输赢翻倍                                                                              |

天胡：庄家起手14张满足胡牌条件，视为天和，并且不计算庄家、自摸等翻倍条件。

地胡：庄家打出第一块牌使得闲家胡牌，视为地胡。地胡三家都需给付。

跟庄：在开局第一圈，庄家出的第一张牌，三个闲家在第一圈每人都出一张，则庄家应按规定向其他三家给付底分。抄庄与否不影响牌局进行。比如就是庄家出北风，三个闲家每人都出一张北风。

### 面子规则

- 普通刻子：三张相同牌；精牌可补足。
- 数牌顺子：同一花色连续三张；精牌可补足缺张。
- 乱风顺：东、南、西、北中任意三种不同风牌可组成一组面子。
- 三元顺：中、发、白可组成一组面子。
- 将牌可以是同牌对子、单张加 1 张精牌，或两张精牌。

十三烂判定直接检查实际 14 张手牌，可以用精牌替代，也不要求特定数量的字牌。七星十三烂在十三烂基础上要求东南西北中发白七字齐全，七字允许精牌替补（白板只能替补精牌面或白板本身），不要求物理在手。十三幺的 13 种幺九/字牌同样允许精牌替补缺失牌，且其中一种须成对。

## 4. 弃牌后的响应与优先级

任一玩家弃牌后，其他三家可检查胡、碰、杠；只有弃牌者的下家可吃。

精排可以打出，可以作为吃、碰、杠。但是这种情况精牌只能作为普通牌使用。

服务流程的优先级为：

1. 胡；
2. 杠（明杠）；
3. 碰；
4. 吃。

当前控制流程在存在多个可胡玩家时，按玩家遍历顺序处理第一个胡牌选项；并未实现一炮多响。

### 吃牌

仅下家可吃，支持：

- 数牌顺子：同花色的连续三张；
- 乱风吃：东、南、西、北中任意三种不同风牌；
- 箭牌吃：中、发、白三种。

### 碰与明杠

- 碰：手中有至少两张与弃牌相同的牌；精牌按自身牌面作为普通牌使用。
- 明杠：手中有三张与弃牌相同的牌；精牌按自身牌面作为普通牌使用。
- 风杠：仅支持暗杠，暗杠时需要亮明出来，不要暗扣两张；不支持大明杠和补杠（副露落地为顺子，不是刻子）

### 跟庄

开局第一圈：庄家打出的第一张牌（首弃），若三个闲家在第一圈各出一张同牌（跟打），庄家向其他三家各给付一个底分 `B`（100）。

- 例如庄家首弃北风，三个闲家第一张都打出北风 → 庄家 −300，三家各 +100。
- 跟庄为即时结算，不影响牌局进行（抄庄与否均不中断流程）。
- 窗口失效：任意闲家出的牌与庄家首弃不同、庄家再次出牌、同一闲家重复出牌，或期间发生吃、碰、杠、胡等打断第一圈的动作。
- 本规则同样适用于莲花广麻玩法。

## 5. 杠牌

| 杠型      | 条件                        | 杠后动作                |
| ------- | ------------------------- | ------------------- |
| 暗杠      | 手牌中有 4 张相同的牌                 | 移除 4 张，立即补 1 张      |
| 明杠（直杠）  | 手中有 3 张相同牌，取得他人弃出的第 4 张 | 移除弃牌及手中 3 张，立即补 1 张 |
| 加杠（补杠）  | 已碰某牌，之后手中再有该牌 1 张         | 将碰升级为杠，立即补 1 张      |
| 风杠（乱风杠） | 手牌同时持有东、南、西、北各 1 张        | 移除四种风牌，作为暗杠处理并补 1 张 |

杠后应从牌尾补牌。

## 6. 杠分

基础单位 `B = 100`。杠分在开杠时立即结算：

| 杠型 | 付款方式        |       杠者总收益 |
| -- | ----------- | ----------: |
| 加杠 | 其余三家各付 `1B` | `+3B`（+300） |
| 明杠 | 放杠者付 `1B`   | `+1B`（+100） |
| 暗杠 | 其余三家各付 `2B` | `+6B`（+600） |
| 风杠 | 其余三家各付 `2B` | `+6B`（+600） |

## 7. 胡牌结算

设基础胡牌单位为：

`H = 100 × 基础番数`

其中平胡为 1 番，七对子和十三烂为 2 番。庄家、自摸、抢杠会在前端详情中显示倍数标签。无论点炮还是自摸，未胡的三家都必须支付分数；普通点炮时，点炮者的那一笔支付再翻倍。

| 胡牌情形 | 庄家支付 | 点炮闲家支付 | 其他闲家支付 | 赢家总收益 |
| ----- | ---: | ------: | ------: | ----: |
| 庄家自摸 | — | — | 三家各 `4H` | `12H` |
| 庄家点炮给闲家 | `4H` | — | 另外两家各 `1H` | `6H` |
| 闲家自摸 | `4H` | — | 另外两家各 `2H` | `8H` |
| 闲家点庄家 | — | `4H` | 另外两家各 `2H` | `8H` |
| 闲家点闲家 | `2H` | `2H` | 另一家 `1H` | `5H` |

其中：

- `H = 100 × 基础番数`；
- 每位输家分别计算：`支付 = H × 自摸倍率 × 点炮倍率 × 庄家倍率`；
- 自摸时三家支付均乘 `2`；普通点炮时只有点炮者乘 `2`；
- 一笔支付的赢家或输家只要有一方是庄家，该笔支付乘 `2`；
- 点炮者不包三家，另外两家仍按各自身份支付；点炮牌来源记录为 `from_idx`。
- 拦胡制、没有一炮多响。

## 8. 流局、听牌与展示

- 通用父类会在普通牌堆耗尽时设置流局；但 `JingGame` 采用物理牌墙并覆盖摸牌方法，未在该覆盖方法中显式处理牌墙耗尽，因此需额外测试确认牌墙摸完时是否能安全流局。
- 系统会为 0 号玩家计算“打哪张后听哪些牌”、对应番型及剩余可见张数，并回传给前端。
- 听牌剩余张数按：4 - 自己手牌中该牌数量 - 桌面所有弃牌与副露中的该牌数量。其他玩家暗手牌不计入。
