## 2026-09-08：血流联机节奏与展示对齐（第二轮）

实玩反馈定位并修复 5 处与本地不一致：

- **节奏为零**：REST 建房注入的是经典房间的 `PLAY_PACE`（dict），会话当成 0 丢弃 → 机器人瞬移。新增 `BLOOD_FLOW_PACE`（AI 思考 650ms、摸牌/弃牌 450ms、碰吃 650ms、明杠 550ms、暗杠/补杠 600ms、抢杠前 650ms、胡牌按档位 3015/3180/3480ms + 多响 1500ms + 交接 100ms），按「刚发生的动作」选择停顿；`pace=0` 仍为测试无节奏。
- **自动出牌**：倒计时与过期 deadline 原本在外层批次开始计时，机器人几个窗口耗掉数秒后轮到真人就立刻过期。改为**真人窗口出现时重新计时**（读秒与过期同源）。
- **倒计时缺失**：快照 `deadlineAt` 恒为 0。改为真人待决策窗口下发墙钟截止时间；决策窗口对齐前端 `remoteDecisionMs`（25s）。
- **东0局**：局号 0-based → 对玩家 1-based（东1局），回执校验同口径；`matchFinished` 也因此正确。
- **三家 profile 闪**：快照发的是引擎占位名 `玩家1..4` + 空头像 → `<img>` 每次快照报错回退造成闪烁。改为下发房间座位身份（昵称/头像/角色/`playerKind`/`isLlm`），前端在映射期补座位默认头像；另修入房昵称在切槽后才读取导致显示「玩家」的问题。

验证：房间测试 10 项（含身份/读秒/节奏档位）；e2e 断言「东1局 + 本家与对手昵称 + 读秒 1–25s + 弃牌流水」，**1 passed（29.2s）**；后端 pytest **579 通过**（test_pace 一例并发 flake 单独复跑 11/11）；前端 **1211 通过 / 2 跳过** + typecheck。

仍未对齐：服务端 AI 席位的动作台词与局末感言（本地由前端 LLM 生成，联机在服务端产生但未下发）。
## 2026-09-08：血流联机局内过场数据补齐（动作流水 / 弃牌流水）

排查发现联机对局中**碰/吃/杠/补杠/暗杠/乱风杠/胡的动作字、弃牌音效与牌名播报、牌河高亮全部缺失**：后端快照把 `actionEvents` 写死为 `[]`、`lastDiscardAction` 写死为 `null`（`blood_flow_room.py`）。

- **房间快照**：`actionEvents` 与 `lastDiscardAction` 改为真实下发（弃牌流水取自 `engine.discard_actions`）。

- 验证：后端 pytest **577 通过**；双浏览器 e2e **1 passed（29.9s）**。

## 2026-09-08：血流联机局间过场（下一局确认）
