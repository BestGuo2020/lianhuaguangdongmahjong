# 路径 A：单条假设的可测性预筛（2026-09-18）

> **零 API**。目的：在花 1200 局/臂之前，先判断"这条假设**有没有可能**被测出来"。
> 探针 `tmp/hypothesis-prescreen.test.ts`；分析 `node tmp/prescreen-analyze.mjs 1200`；
> 原始数据 `tmp/bulk/prescreen-prescreen-*.json`；摘要 `tmp/bulk/prescreen-summary.json`。
> 规模：1200 局 / 8 片 / 8 分钟。

## 方法（为什么这比"直接跑 A/B"省钱）

对每条假设，在同一批**真实局面**上测两个量：

1. **`firesPerRound`** —— 修改后的规则每局真正改变本地决策的次数；
2. **`meanValueDelta`** —— 每次触发时"本地最优候选价值"（点）的变化量。

`信号 = 触发次数 × 值差`（点/局），与**实测噪声地板**比较：
配对 A/B 在 n 局/臂下的可检出效应 ≈ `2.8 × SD / √n`。

**实测噪声地板**：每局四家净分绝对值和 **5,862 点**，每种子 SD **5,634 点**
→ 1200 局/臂只能检出 **455 点/局**；600 局/臂 644 点；3000 局/臂 288 点。

## 三条有解释力的机制发现

### ① H4 为什么"怎么跑都测不出"——系数选错了维度

H4 把档位系数从 `0.25/0.1/0` 提到 `0.4/0.18/0.05`。这个系数是**按公开张数选档的乘数**：
同一档内的所有牌**一起乘同一个数** → **排序完全不变**（只是整体平移）。

- 诊断：**20.1% 的窗口**里，全部弃牌候选都落在同一个公开张数档 → 这些窗口 H4 **结构上**
  永远无法影响决策。
- 实测每次触发的值差只有 **−10.7 点**（对比 H5 的 3,604 点）。
- 结论：H4 不是"效果小"，而是**在"改变本地选择"这条路径上几乎没有杠杆**。
  它要产生 455 点/局的信号，需要把值差放大 40 倍 —— 这不现实。

### ② H1 为什么只能在 0.18 次/局上触发——它是"一次性"门槛

首胡门槛**只在未锁手时**介入（`if (view.ownScore && payment < ev.floor && potentialTotal >= potentialFloor)`），
所以每局每座位**最多影响首胡那一次**决策。分支命中诊断印证了这一点：

```
win-unlocked(门槛介入) 13,795 | payment<floor(基线拒胡) 14,753 | payment>=floor(基线就胡) 36,659 | win-locked(门槛不介入) 37,617
```

"基线拒胡"有 14,753 次，但其中**只有 0.18 次/局（≈216 次）**同时满足"新门槛会接受"且真的改变了选择。
所以"降低门槛能让胡牌 +3~6%"这个预测，**在机制上就没有对应的触发空间**——这与 A/B 实测的
−0.46%（不显著）互相印证。

### ③ H3 出现了一个**未解释的缺口**（必须记下来）

预筛显示 H3 的触发是 **0.00 次/局**（1200 局里一次都没翻动本地选择），但 A/B 实测却给出
wins **−0.77%、t = −2.86**（修复配置 bug 之后）。两者矛盾。

最可能的原因：**探针测的面太窄**。H3 的触发点是"自摸窗口改张 EV"（`reformCandidates[].ev`
走 `chainEvEst`），而 H3 比较的是每个**弃牌候选**后面跟着的那个 `chainEvEst` —— 这些值对**同一手牌
的不同弃牌**都很小，难以翻动排序；而在真实对局里，`chainHorizon` 影响的是**整局走向**
（改张决策 → 听口变化 → 后续窗口全变）。也就是说：**A/B 测到的可能是级联效应，而不是单点翻转**。

这条缺口没解决，所以 H3 的 −0.77% 我**既不撤也不加强**，标为"机制未定位"。

## 直接结论：路径 A 该怎么做

1. **只跑 H5 的全量 A/B**（需要 ~1 局/臂就够，实际跑 1200 局/臂已经做过：胡牌 +16.7%、平均倍率 −22.8%，**已判定为坏**）。
   换句话说：**预筛确认 H5 是唯一"一眼能看出好坏"的假设，而它已经被否决了。**
2. **H2/H1 想测就得把样本量提到 1,700 / 5,000 局/臂**（纯本地零 API，约 25 分钟 / 70 分钟）。
   这是"能不能测"的问题，不是"有没有效果"的问题。
3. **H4 直接放弃**，或**改设计**——不要把系数整体上调，而是让"风险成本"进入**档位之外**的维度
   （例如让它影响"是否弃胡兜牌"的政策判断，而不是给同档候选一起乘同一个数）。
4. **H3 先定位机制再谈验证**：需要在探针里记录"改张决策本身"的翻转次数，而不是弃牌候选的价值排序。

## 对"路径 A"这个方法本身的评价

**它成功了**：8 分钟零成本，把"5 条假设要不要各花 1200 局"变成了"1 条值得跑、2 条要加样本、2 条结构上免谈"，
并且顺带**否掉了自己第一版里两个错的事件模型**（H3 的"统一按 5/8 缩放"、H4 的"以为会改排序"）。

**它的边界**：预筛量的是**直接效应**（单点决策翻转），**量不到级联效应**（H3 那个缺口就是证据）。
所以预筛的结论要这样用：
- 判定 **"✗ 结构性检不出"** → 可信（触发率本身就接近零，没有级联的种子）；
- 判定 **"✓ 值得跑"** → 可信（直接效应已超地板）；
- 判定 **"△ 边缘"** → **不能当成"没效果"**，只能当成"现有样本量测不出"。
