# 独立分歧窗口：净收益差与放炮成本的同口径验证

## 结果与决策

本轮把候选收益与风险统一为引擎实际支付的**分数**，分开验证当前弃牌即时支付、未来八次真实自身摸牌内的分量、以及本局剩余全程。已完成独立训练/留出和冻结风险尺度比较，未修改生产策略或风险权重。

即时风险代理的点数校准有改善；但当前代理差不能可靠解释后续八摸的点炮支出差，标定落在零边界，没有产生新的换序。新候选的原牌墙整局净差为 -124，区间跨零。不能把短期置换均值的正信号当整局强度证据。

## 采样与候选冻结

- 按运行前协议，训练扫描 310001–310256、留出扫描 311001–311256。每个新源种子最多取第一个合格首胡改张分歧，分别得到 **22 / 20 个窗口**，已达到最低数，无须扩展。
- 所有座位均使用冻结 source-v2 + 1.2；比较旧候选与条件模型提出的新候选。窗口命中后停止该来源轨迹并先写入候选、公开特征及快照，再生成标签。512 是独立开局扫描次数，不是 512 场完整对抗。
- 每窗口使用原剩余牌墙和 8 个成对置换，两种候选在同一墙序下执行；其余暗手固定，后续全部使用相同冻结 source-v2 政策。有效标签共 42 × 9 × 2 = **756 条候选续局**，统计独立单位仍是 22 / 20 个源窗口。
- 置换只平均墙序波动，不是对全部隐藏状态的后验，也不是完整四局比赛。快照只用于离线标签；决策始终读取合法座位视角。
- 留出标签未参与系数拟合。风险尺度文件写入后拒绝重拟合，留出评估检查模型哈希不变。

## 支付口径

每段记账均使用同一恒等式，并与引擎分数核对：

`净收益 = 胡牌毛收入 − 我方点炮支出 − 其他胡牌支付 + 杠净额`。

其他胡牌支付包括他家自摸、杠开及我方被抢杠等。当前强制弃牌造成的即时支付是点炮支出的子项，按来源事件 ID 识别；一炮多响逐赢家累加，但不会再从净收益重复扣除。

八摸窗口截止于第九次**真实**自身摸牌决策之前，或提前流局；补摸计入，吃碰后的出牌回合不计。初版检查发现引擎的吃碰后窗口也可能使用 `draw` 来源标识，因而补上 `drawnTileIndex >= 0` 条件、前缀分数核对与专门回归。全部候选不变，标签重算为 `actual-draws-v2`；旧标签未用于拟合或本报告。初版流水线还有清单比待处理列表先完成的边界错误，已修复；最终四批标签均通过完整窗口数和快照哈希检查。

## 独立留出的配对净差

差值统一为“新候选 − 旧候选”。先对每个窗口的 8 个置换取均值，再对 20 个源窗口 bootstrap 4000 次；原墙结果单列，不将重复墙序当新源样本。

| 时段 / 牌墙 | 平均净差 | 95% 源窗口区间 |
|---|---:|---:|
| 八摸 / 原墙 | +84.00 | [-67.00, 286.00] |
| 八摸 / 置换均值 | +63.625 | [2.25, 156.0625] |
| 本局剩余 / 原墙 | -124.00 | [-374.50, 83.50] |
| 本局剩余 / 置换均值 | +52.75 | [-9.1875, 138.625] |

八摸置换均值的分量如下，支付项为“成本变化”，正数意味着新候选多付：

| 分量 | 新−旧均值 |
|---|---:|
| 胡牌毛收入 | +59.625 |
| 全部点炮支出 | -0.0625 |
| 其中：当前弃牌即时支出 | +7.000 |
| 其他胡牌支付 | -4.3125 |
| 杠净额 | -0.375 |
| 净收益 | +63.625 |

即时成本增加并不等于长期点炮成本也增加，后续路径会抵消或放大它。反之，八摸领先也不等于本局最终领先。单个窗口 311126 的置换八摸净差 +811.25，占合并净差约 64%，存在明显尾部集中，不能仅凭短期区间正就推广。

## 风险代理到实际分数的训练与留出

### 当前弃牌即时支付

只在 22 个训练源窗口上，用两个候选的即时真实支付拟合非负、过原点的一维尺度。44 个候选标签中仅 6 个支付非零；两臂不是 44 个独立来源。

得到 `即时预计支付点数 = 0.07705203 × 原风险代理`。例如代理 64 在此模型中约为 4.93 分，而不是可直接从收益扣除的 64 分。它只针对本轮合格分歧窗口和冻结对手，不是新的全局规则常数。

| 留出即时支付预测 | MAE | RMSE | 平均偏差（预测−实际） |
|---|---:|---:|---:|
| 原风险代理直接作点数 | 67.84 | 87.15 | +66.16 |
| 预测零 | 13.00 | 24.90 | -13.00 |
| 训练支付均值 8.6364 | 15.59 | 21.68 | -4.36 |
| 冻结的 0.07705203 尺度 | 11.66 | 20.03 | -6.90 |

相对零预测的均方误差改善，按源窗口平均为 +218.93，95% 区间 [72.55, 392.33]。校准有信息，但仍低估平均支付且正标签少；不能因此直接缩小正式 AI 的全局防守权重。

### 八摸内配对点炮支付差

另以“新旧风险代理差”拟合“同一八摸范围内的置换平均点炮支付差”。训练中只有 8 个窗口代理差非零、4 个窗口成本差非零；非负拟合得到 **0 边界**。

留出成本差 MAE：原代理差 24.0425，零差预测 7.5625，校准后也是 7.5625。相对原代理看似改善 16.48 [6.40, 28.00]，实际只是退回零差，不能称为学到了有效的长期风险排序，更不表示未来风险为零。

以 `预测毛收入差 − 校准点炮差` 作部分净收益代理，留出 MAE 为 78.43；拿它预测包含其他支付及杠净额的完整八摸净差，MAE 为 84.70，与只用毛收入差完全相同。因尺度为零，没有任何窗口改变选择，不能把“总选择新候选”的 +63.625 重命名为风险调整的策略增益。

## 一个新留出窗口说明两种不足

311126、座位 1、墙余 48，旧弃八筒，新弃一筒：

- 两张牌原风险代理都是 **160**，但真实即时支付分别为 **0 / 70**。缩放同一个值不能在这个具体样本中区分两张牌；这也不意味着在线策略能知道隐藏听口，不应按结果特判。
- 原墙八摸：旧净收益 -980，新 +590，差 **+1570**。
- 同一原墙到本局结束：旧净收益 +3020，新 +1250，差 **-1770**。
- 整局反转主要来自毛收入：旧 4050、新 2020；新候选的整局点炮支出反而更少（70 对 330）。

因此，不能把所有排序失败归因于“风险扣得不够”，也不能只看八摸结果。需要检验剩余尾部收入与风险的预测，而不是把当前弃牌的启发式成本机械扩成整个后续成本。

## 交付与验收

本轮没有修改生产规则、模型系数或默认排序。新增的是可复现的候选冻结、成对续局、同时间范围记账、风险点数标定及独立留出分析工具。四批采集和四批修正标签生成均通过；即时支付在同候选的墙序置换间一致，前缀/终局分数恒等式通过。3 项记账与同快照 A/A 测试、脚本类型检查和分析器检查通过。仅改离线工具和文档，未重复部署或 UI 验收。

归档 `paired-window-risk-scale-2026-09-20.json`、`paired-window-risk-holdout-2026-09-20.json` 和 `paired-window-risk-manifests-2026-09-20.json` 保存冻结尺度、源窗口分量及结果、快照哈希与采集配置。隐藏状态 `.v8` 留在本地 work，不被在线策略读取。原始公开计划和逐墙结果位于 `work/blood-flow-paired/<批次>/`。

下一步若继续，应在新样本上分别验证即时点炮的公开特征模型、后续支付差，以及八摸之后的尾部价值。现有证据支持统一支付口径和保留即时校准实验，不支持直接用一个缩放系数改写正式排序。
