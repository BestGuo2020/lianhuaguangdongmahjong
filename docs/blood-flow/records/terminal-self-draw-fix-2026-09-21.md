# 末张自摸候选与连锁收入边界修复

## 复现证据

来自分析包 e27b1ef3，东2局 `round-2/window/336`，绝对座位1。四局579条命令已逐窗口、手牌与最终分数重放一致。末张墙余0，规则允许自摸，每家10分、合计30分；旧 LLM 碰碰胡路线撤掉胡牌，并向模型显示打六筒后的1480连锁收入。实际弃六筒后支付130，直接胡的确定终局差为160分。不能把160分推广成其他窗口或整场损失。

回归夹具 `terminalSelfDraw.fixture.json` 为该窗口的单座视角，只保存本家暗手与公开信息，无对手暗手或未来牌墙。

## 修改

- 最后自摸、规则仍提供胡牌时，LLM 与普通 AI 的大牌路线层均不再撤胡；没有合法胡时不补造动作。
- 普通 AI／LLM 本地推荐在这个窗口选择胡，不再因首胡门槛或改张潜力放弃终局确定收入。
- EV 上下文在墙余0时将胡后连锁、改张连锁、继续发育收入置零；三种预测模式一致，立即收入仍按引擎计分。
- 末张胡牌候选明确说明胡后结束、改张没有后续摸牌收益，且不附加低番继续发育理由。玩家端改张提示同样停止。

LLM 仍可从合法候选选择，没有把所有决策强制改成本地推荐。修复不启用 LLM 的 source-v2，不调整1.2阈值，不推广一般残局路线释放，不改变末张弃牌竞争中的吃碰杠优先级。墙余大于0时保持原有行为；后续是否扩展残局约束需独立验证。

## 验收

- 真实窗口回归3项：候选／推荐／提示一致、三种预测与改张收益为零、正墙余和竞争窗口边界、输入不变与无隐藏信息。
- 全量前端184个测试文件、1855项通过，原有1个文件／2项跳过。
- 最终候选文案补充后，相关EV与末张回归共11项通过；Vue类型检查与最终生产构建通过。构建保留既有大chunk提示。
- 真实浏览器 worker 东风场与半庄场2项通过（1.5分钟），包括完整局数与总分守恒检查。

该修复是有确定反例的边界正确性修复，不将局部160分收益宣称为平均牌力提升；未调用付费LLM或追加随机对抗。
