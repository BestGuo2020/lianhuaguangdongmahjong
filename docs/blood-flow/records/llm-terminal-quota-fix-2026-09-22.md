# LLM 末张确定性选择与额度耗尽暂停

## 证据与范围

回放65418b0d的东1局 `round-1/window/351`：胡牌候选、推荐胡与零连锁收益都正确，但千问仍弃六万。原局精确分叉为自摸收入60对实际付款120，确定差180分。同一回放另有25次明确的免费额度耗尽403，发生在南3、南4局。

本轮修复决策执行与连接可用性，不按单场输赢调整一般策略、不扩展所有残局的强制胡牌。

## 末张直接选择

在请求供应商、计算听口或进入模型闸门之前检查：当前是本家最后自摸窗口，规则提供胡牌，确定支付为正，候选只有胡／过／弃牌。满足条件直接返回合法胡牌，不请求模型、不让风格覆盖；过期窗口不执行。正墙余、他家末张弃牌响应和其他特殊候选不使用此短路。

分析记录为 `source=local-strategy`、`sourceReason=terminal-self-draw`，保留合法动作和本次实际推荐，不产生虚构的模型尝试。

## 连接暂停与恢复

- 连接按规范化地址、密钥、型号识别，不按座位、昵称、风格或超时预算识别。共用配置的座位共享状态；变更地址／密钥／型号使用另一连接。
- 只识别402／403／429响应中明确的额度／余额耗尽消息或指定错误码；普通403、鉴权错误、短时速率限制、模糊quota exceeded和输出截断不暂停。
- HTTP返回额度耗尽后，底层立即暂停该连接，后续游戏请求在发送前阻止。已经在飞的请求分别收尾，成功也不自动清除暂停。
- 血流运行时在暂停期间使用正式本地AI，跨座位、跨局不重发模型请求。首次额度错误后的选择记为 `model-fallback / quota-exhausted`；后续接管记为 `local-strategy / quota-paused`，没有新增模型尝试记录。
- 牌桌提示一次已由本地AI接管；AI设置列出暂停配置，将该配置的“测试连接”显示为“重新连接”。补充额度后用户主动点击，成功才解除暂停。
- 同连接并发点击共用一个探测；探测期间游戏请求继续被阻止。探测失败保持暂停，探测期间新到达的额度错误也不能被成功探测覆盖。
- 不自动开启付费、不修改用户供应商配置，不额外请求余额接口。暂停状态仅在当前页面进程内保存，不持久化含凭据的连接标识；刷新页面是新会话，可能再尝试一次。跨浏览器／后端进程不共享此内存状态。

## 验证

单元测试覆盖回放末张局面、模型即使想弃牌也不会被调用、非终局不强制、精确额度分类、同配置跨风格／服务实例暂停、不同密钥／型号隔离、失败探测不恢复、并发探测合并、已在飞请求收尾，以及分析来源和原因落库。

全量前端190个测试文件、1933项通过，原有1文件／2项跳过；Vue类型检查和生产构建通过（仅既有大chunk提示）。

浏览器4项通过（3.4分钟）：真实worker东风场、半庄场；设置页暂停提示与单次重连探测／恢复；三个LLM座位共用耗尽配置后以本地AI完成四局东风场且总分守恒，后续三局模型请求数不增加。供应商接口全部模拟，未消耗真实额度。
