## E09 千局与条件压力

[千局报告](simulation.md)使用实际 TypeScript 引擎，提交 `757dabc`，种子 1～1000，耗时约 56 秒。1000 局全部结束，3772 条胡牌记录中 807 次独立首次成牌、2965 次锁手后重复胡；硬胡占 10.39%，随机样本没有封顶，不能据此推断稀有大牌不存在。

千局主样本使用合法动作压力策略（有胡即胡、随机合法弃牌、首个副露）。另已完成[三策略分布](strategies.md)：相同种子 1～100，随机压力、生产规则 AI、首胡至少 40 分的规则 AI 各 100 局，约 213 秒全部通过。三者首次成牌分别为 83/359/146 次，平均首胡剩余墙长 30.17/60.61/34.08；重复胡、硬胡/封顶、分差、命令数和番型频次均独立记录。这是四席自我对局分布，未测策略对抗胜率、真实 LLM 强度或长期平衡；没有沿用旧 Python 数值。

另有条件大牌三响：同一张红中同时完成混幺九/四暗刻、大四喜/字一色/四暗刻、混一色/四暗刻，分别支付 220/600/180 分，终局前余额为 `[1000, 2220, 2600, 2180]`，物理源牌只入档一次。黄金输入另覆盖十三幺自然硬胡点炮 320 分、自摸单家 640 分及封顶边界。条件样本不混入随机发生率。

复用原 winEffectPresenter 的光束、星芒和粒子，每个赢家定位到对应新牌的楼层；不重复添加实体牌，不新增声音，不修改权威动作节拍。3D 装饰至少保留 750ms 以看清入口渐显，高番沿用队列的 1400/1600ms；当时中央文字队列仍独立；后由 E11 统一，见当前验收记录。多响各席独立，资源不被下一次牌桌实例重建清除，结束/恢复/卸载时清理，历史快照不补播。
