# 预测计分、摸牌机会与有限步搜索

## 范围与实现

- `incomeForecast.ts` 的未来单次收入直接调用引擎同一个 `evaluateWin`，输入保留胡牌张、来源、完整副露、精牌和白板规则；未来窗口没有天/地胡加成。自摸乘三家，点炮乘一家，非法点炮计零。缓存最多 20,000 项，键包含上述全部输入。
- `chainForecast: 'self-draw-v1'` 在 `bloodFlowEvContext` 内统一胡后锁手、改张和过抢杠的后续自摸估值；`legacy` 或不填保持旧模型。正式默认仍为 `legacy`，前三项已验收的策略开关保持开启。
- 新模型为**固定手牌、正常轮转、未见牌可交换假设下的未来自摸毛收入分量**。它不是完整净收益模型，也不是有保证的收入下界。未见牌包含对手暗手，不能全部视为墙牌。
- 若下一次我方摸牌距现在为 `offset` 张墙牌，未来自摸次数为 `min(horizon, max(0, 1 + floor((wall-offset)/4)))`；墙余小于 offset 时为零。自摸后 offset=4，外来胡按来源座位计算；过抢杠需额外扣除杠家的一次补摸。
- 每次摸到某牌的概率为 `该牌未见张数 / 全部未见张数`；固定手牌的未来期望为次数乘单次期望，不再额外乘 `selfDrawWeight=6`。无放回抽样的线性期望同样成立。没有给未知对手弃牌概率编造常数。
- 点炮机会、鸣牌跳巡、未来杠牌/补摸及手牌变化尚未标定，所以新模型先作为可切换实验，不能直接把其数值和上一轮“全部后续毛收入”校准标签混用。

## 有限步搜索

`scripts/blood-flow-bounded-search.ts` 只接收当前座位视角。仅在未锁手自摸首胡窗口、新模型本来选择胡、尚有至少两次正常自摸机会时展开：

1. 取允许弃牌里固定手牌估值最高的一个听牌改张候选。
2. 枚举下一次自摸的所有未见牌型，按公开信息分配概率。
3. 比较胡后锁手/保留原手，以及按未见听口张数选出的一个再改张候选。
4. 叶子统一使用新自摸收入模型，且扣掉这次已展开的摸牌机会。超过原胡牌价值的既有 1.2 倍门槛才改变动作。

这是一个下一次摸牌、一次再改张的窄搜索，最多 34 个机会分支、68 个叶子；不是完整对手博弈树。未来改张没有完整模拟放炮和副露竞争，可能乐观。节点上限不是毫秒级硬时限：单次规范计分本身仍可能昂贵。因此搜索仅放在离线脚本，没有导入正式 AI。

## 完整对局协议

先各用 2 个种子试跑，再固定配置各用独立 8 个种子复验，试跑与复验分开报告。四组分别为：新模型对正式模型 × 混合/防守对手；搜索对新模型 × 混合/防守对手。搜索增益不能直接当作相对正式版的增益。

每种子四座轮换；每座候选、对照使用相同四局发牌与固定对手策略，分数跨四局携带。双方都走完整东风场，合法动作和牌守恒由引擎检查。政策只接收公开视角，不能读取原始种子、对手暗手、牌墙顺序或未来标签。复用共同前缀，首次分歧后完整重打后缀。

统计按源种子聚类（同一发牌的四个座位不当四个独立样本），4,000 次 bootstrap。两个对手配置都属于合成策略，不能代表真人或所有强对手。延迟统计受同机并发负载影响，仅用于发现明显超预算。

试跑：每组 2 个种子、8 场候选及 8 场对照。新模型混合/防守增量均值分别 +1201.88 / +466.25；搜索分别 +864.38 / +1241.25。两种子区间不可靠，不据此推广。搜索试跑共展开 25 次，12 次返回改张（包含同窗口重复调用，不能解释为 12 个独立局面）。

### 独立复验结果

每项处理各 16 个新源种子、64 场候选及 64 场对照；两项共 1,024 局逻辑对局。加试跑共 1,280 局（共同前缀复用，实际执行命令量小于全部从头重打）。表中单位为每座完整东风场的配对净分增量。

| 处理 / 对手 | 均值 | 源种子 bootstrap 95% 区间 | 改变的场次 |
|---|---:|---:|---:|
| 新模型 / 混合 | +139.06 | [70.63, 234.69] | 17/32 |
| 新模型 / 防守 | +17.03 | [-183.13, 235.63] | 14/32 |
| 新模型 / 合并 | +78.05 | [-36.88, 193.59] | 31/64 |
| 搜索对新模型 / 混合 | -3.75 | [-175.63, 150.31] | 4/32 |
| 搜索对新模型 / 防守 | +824.38 | [133.44, 1976.88] | 7/32 |
| 搜索对新模型 / 合并 | +410.31 | [14.53, 1037.50] | 11/64 |

新模型第一名比例差 +3.13 个百分点，区间 [0, 7.81]；搜索 +4.69 个百分点，区间 [0, 12.50]。搜索平均名次差区间跨零。不能声称稳定改善排名。

搜索合并均值虽为正，但单个源种子 261308 的四座均值 +4757.50，贡献了合并总增量约 72.5%；去掉这个种子后均值约 +120.50。此敏感性检查不是重新挑选样本，也不把剩余样本当独立确认。混合对手没有明确增益，样本只有每组八个源种子，泛化证据不足。

延迟：新模型全部调用 P95 为 1.79 / 2.53 ms，最大 214 / 363 ms；搜索实际展开调用 P95 为 3949 / 2701 ms，最大分别 7753 / 3650 ms。全部调用 P95 很低只是因为搜索大多数窗口不展开，不能用它掩盖卡顿。复验共展开 72 次、24 次返回改张，包含重复调用；实际发生差异的完整场次为 11。

### 两类损失复现

另用固定种子完整重放两个防守对手负例，断言结果完全一致，保存首个公开分歧窗口和两套 EV：

- 261106，座位 3，第二局墙余 51：旧策略弃红中，新模型立即胡；整场差 -1900。旧胡牌 EV 1812.94、最佳改张 2620.06；新胡牌 EV 831.43、最佳改张 516.92（最佳弃牌方向也换了）。
- 261108，座位 1，第四局墙余 51：旧策略胡，新模型弃八万；整场差 -1830。旧最佳改张 3018.04 略低于 `1.2 × 2534.73`；新最佳改张 1355.60 超过 `1.2 × 923.74`，因此跨过门槛。

这是同牌墙后缀的可复现损失，不等于证明另一动作在未知牌墙分布下必然更优。两个方向都能失败，不能只按“早胡/晚胡”调整一条全局规则。计分与尺度变了以后，旧改张阈值、未来可继续改张的价值，以及未建模的点炮/鸣牌机会需要分开校准。两例是事后诊断样本，后续调参不能再将它们算独立验证。

### 决策

1. 规范计分一致性通过，保留实现和有界缓存；新机会模型可通过配置调用，但正式默认仍 `legacy`。前三项正式修复不回退。
2. 不默认推广自摸分量模型：总体验证区间跨零，且缺失点炮、未来鸣牌等收入/机会；也没有测量其相对真实后续自摸收入的校准误差。
3. 不接入实时搜索：性能明确不达标，收益集中且对混合对手无明确增益。已实现并实际对抗验证，不能据此宣布搜索无用或 AI 已达上限。
4. 下一阶段优先在新源种子上记录真实后续自摸/点炮收入和摸牌次数，分量校准后重验改张门槛；同时对计分拆解复用和候选剪枝做成本优化，再检验扩大候选/步数。避免对这两个负例做特判。

持久证据：`forecast-search-pilot-2026-09-20.json`、`forecast-search-validation-2026-09-20.json`（含完整配置、指纹、配对分数及动作分歧）、`forecast-score-audit-2026-09-20.json`、`forecast-loss-reproductions-2026-09-20.json`。这些记录与政策模块隔离，不作为在线决策输入。
