# 来源机会、改张阈值与搜索成本的后续验证

## 实现与边界

本轮新增实验配置 `chainForecast: 'source-v2'`，接受显式 `opportunityCalibration`。正式默认仍为 `legacy`；之前已验收的三个策略修复继续开启。

未来收入拆为两部分：规范自摸单次收入 × 有效自摸次数，以及规范点炮单次收入 × 有效对手弃牌次数。单次收入共用引擎计分，外来精牌不能胡时仍为零。未知牌概率分母包括对手暗手，不能把全部未见牌当墙牌。

基础轮转以“第九次自身摸牌之前或流局”为八次摸牌展望终点，自摸后的正常机会最多为 8 次自摸及 27 次其他座位摸牌。末巡不足四张时，自己可能不能再摸，但仍可能接到对手点炮。过抢杠继续扣除杠家的一次补摸。

训练数据将真实自摸次数、对手摸牌次数、对手弃牌次数、自摸收入、点炮/抢杠收入分开记录。未来吃碰跳巡、杠补摸、对手自摸消耗牌而不弃牌等，会改变有效次数；本轮用群体倍率修正，而不是伪装成能预测特定对手动作的完整博弈模型。手牌未来开杠/改形、弃牌牌型偏好与来牌竞争仍不在显式转移模型中。

校准窗口是实际首个未锁手自摸胡以后，属于固定锁手的继续收入。把它应用到尚未锁手的改张候选仍有外推风险，特别是改张当前这张弃牌可能立即诱发吃碰。参数必须继续作为实验，不能仅因为加入点炮就宣称模型完整且准确。

## 校准协议和结果

训练与留出各 56 个全新源种子，112 局固定策略模拟。整局归入一个集合，不按窗口随机拆分。训练 270001–270024、270201–270232；留出 270101–270124、270301–270332。座位 0 使用正式策略，其他三家为轮换的混合合成对手；观察四家实际首胡窗口，政策不读取暗手/墙序。

训练产生 64 个有效窗口，留出产生 59 个窗口（来自 41 个源种子）；未产生窗口的局不被补成虚构收入样本。来源倍率先用训练集实际次数与正常轮转次数之比估计，再对自摸和点炮分别做非负、过原点的收入校准。留出数据不参与拟合。

冻结参数：`drawScale=0.9975786925`、`discardScale=0.8990627253`、`selfYield=0.8478712072`、`ronYield=0.9877357078`。这些是这批合成对手下的经验系数，不是规则常数。

| 留出指标 | 旧自摸分量 / 正常轮转 | 未校准双来源 | 校准双来源 |
|---|---:|---:|---:|
| 总收入 MAE | 217.90 | 283.28 | 234.99 |
| 总收入 RMSE | 355.53 | 598.26 | 441.46 |
| 总收入均值预测 | 494.73 | 717.08 | 615.91 |

实际总收入均值 544.41。校准后自摸预测均值 418.46、实际 399.15；点炮预测 197.45、实际 145.25。**双来源校准改善了直接把所有对手摸牌当点炮机会的错误，但没有超过旧自摸分量的整体误差。**

自身摸牌次数 MAE 为 0.0508 → 0.0655（未改善，基础轮转在此分布已很准）；对手弃牌次数 MAE 为 2.0339 → 1.6651、RMSE 为 2.8463 → 2.1391。总收入绝对误差改善按源种子等权的均值 +2.58，95% bootstrap 区间 [-47.57, 46.74]；这与按窗口均匀平均的 MAE 差值不同，不能混用权重。没有稳定改善的证据。

原始采集中的 `wallConsumed` 调试字段在第九摸截断时曾包含已取出但不计入展望的第九张；脚本现已修正。所有拟合/验收都只使用实际自身摸牌数、弃牌数和收入，未使用该字段；持久校准特征也不含该字段。

## 搜索优化及公平基准

- 自摸/杠开按完整手牌多重集缓存规范收入。当前番型目录不依赖是哪一张自摸实例；外来胡保留来牌身份，避免破坏精牌合法性和暗刻判定。
- 搜索内部按完整 14 张牌复用胡牌合法性：先摸 A 再摸 B 与先摸 B 再摸 A 的等价组合不重复判定。
- 增加安全上界：假设所有听口都支付规则封顶，若仍不超过已有分支，跳过该分支的精确叶子计分。此次四案例未实际减少叶子数，不能把收益归功于剪枝。
- 测试同时清空计分缓存和听牌缓存。曾经只清计分缓存导致后测继承热听牌缓存，相关较大提速数字已废弃，不进入最终证据。

| 公开诊断案例 | 未优化合法性查询 ms | 优化 ms | 叶子数 |
|---|---:|---:|---:|
| 01689b18987c2cfd | 1570 | 941 | 66 |
| b76602f2e29d9c92 | 4229 | 2616 | 51 |
| e17f50bdccbd5afe | 3732 | 2717 | 48 |
| 64a6c6a98f52f2e0 | 585 | 607 | 0 |

展开案例减少约 27%–40%；所有案例的动作和 EV 一致，自摸来牌身份置换也与引擎规范计分一致。参考和优化均已使用新自摸计分缓存，因此这里衡量的是搜索合法性复用与上界检查的增量，不是全部优化相对上一轮的严格总提速。单机并发和固定运行次序影响绝对耗时；最慢仍约 2.7 秒，搜索继续离线，不进入实时默认策略。

## 改张阈值协议

冻结以上四个系数，比较 1.0、1.2、1.5 三档改张收益比。训练各 4 个混合对手种子和 4 个防守对手种子，四座轮换，每场四局、跨局携带分数，双方相同牌墙和对手。1.0、1.5 都与同一 1.2 控制配对。

预先固定选择规则：选训练配对均值最高的一档，平局优先 1.2；如果两档均不胜 1.2，则保留 1.2。随后在未触碰种子上验证选择，不再根据留出结果换另一档。后缀完成的对局受引擎合法动作和牌守恒检查；运行结束核验源码指纹。

训练 1.0 对 1.2：均值 -4.06，源种子 bootstrap 95% 区间 [-44.38, 37.19]；1.5 对 1.2：均值 +11.56，区间 [-2.19, 27.19]。均只改变 4/32 场，第一名比例没有变化。按预定规则选择 1.5 进入独立复验，不代表已证明其优于 1.2。

独立复验使用混合对手 272001–272004、防守对手 272101–272104。分别做两组比较：1.5 对同一新模型的 1.2；新模型 + 1.5 对正式旧模型。两种增量分开报告，不能相加或混称阈值改进。

### 独立复验结果

每种比较 8 个源种子、32 场候选及 32 场对照；训练加留出共 1,024 局逻辑对局，另有 112 局机会校准采样。共同前缀复用减少了实际执行量，不改变四座配对口径。

| 比较 | 混合对手均值 | 防守对手均值 | 合并均值及 95% 源种子区间 |
|---|---:|---:|---:|
| 新模型 1.5 对新模型 1.2 | -196.88 | -7.50 | -102.19，[-234.38, 0] |
| 新模型 + 1.5 对正式版 | +301.25 | +139.38 | +220.31，[20.31, 489.69] |

阈值比较只改变 3/32 场，第一名比例差 -3.13 个百分点，区间 [-9.38, 0]。完整模型比较改变 13/32 场，第一名比例差 +3.13 个百分点，区间 [0, 9.38]。训练选择的 1.5 没有在独立样本胜出，**保留原有 1.2**；不因为训练均值略正就调整正式阈值，也不根据留出结果再选择 1.0。

新模型组合相对正式版出现正向得分信号，但每种对手仅四个源种子，且收入校准未优于旧自摸分量。该结果不能拆称为“阈值提高带来收益”，也不能直接证明恢复 1.2 后的新模型已通过同一推广验收。

### 最终决策

1. 双来源机会模型、显式校准参数和末巡点炮处理保留在实验路径；正式默认仍 `legacy`，新模型不默认推广。机会次数已分开测量，但弃牌内容与收益关联仍需要建模，不能宣称已补成完整对手行为模型。
2. 改张阈值维持 1.2。训练、独立复验均完整留档，未把负面结果隐藏或用于事后换档。
3. 搜索合法性复用和安全上界检查保留，等价回归通过。冷缓存展开耗时减少 27%–40%，仍不进入实时策略；上一轮三个已启用修复不回退。
4. 下一项最有依据的工作是按对手是否锁手、弃牌牌型与我方听口价值，检验点炮收入条件分布，并在新种子上验证 source-v2 + 原有 1.2。当前证据不支持继续盲目调高阈值或加深搜索。

- 全量 160 个测试文件、1,652 项测试通过；1 个文件、2 项测试按原设置跳过。

## 复现入口

`scripts/blood-flow-opportunity-observations.test.ts` 用 `BF_OBSERVE=1`、`BF_OBSERVE_FROM`、`BF_OBSERVE_ROUNDS` 收集全新批次；`scripts/blood-flow-opportunity-fit.test.ts` 用 `BF_FIT=1` 按已声明种子集合拟合。校准数据必须先生成，不能只使用阈值对局反向猜系数。

`scripts/blood-flow-opportunity-contest.test.ts` 使用 `BF_SOURCE_RUN=1`、`BF_SOURCE_RATIO`（1/1.2/1.5）、`BF_SOURCE_PANEL`（mixed/defensive）、`BF_SOURCE_MODE`（threshold/production）、`BF_SOURCE_FROM`、`BF_SOURCE_SEEDS`。旧目录拒绝覆盖，完成时检查策略源码指纹。

`node scripts/analyze-blood-flow-opportunity.mjs <完成批次标签...>` 校验完整性、源指纹、校准系数与配对账目，再按源种子聚类计算区间。分析器输出的 `selected` 只在预定训练批次上用于选阈值，留出批次不得用它重新调参。

搜索测试：`node node_modules/vitest/vitest.mjs run --dir scripts blood-flow-search-performance.test.ts`。目前搜索仍使用上一轮固定的自摸分量目标验证等价优化；未通过校准的新双来源模型不接入搜索，以免把模型误差扩大到更多分支。
