# 吃／碰后的副露投影修复（2026-09-20）

## 改动与冻结验证方案

`decideClaim` 的碰／吃候选现向番型估值回调传入「原有副露 + 当前候选形成的新副露」。新牌组包含类型、完整三张牌、被吃／碰的牌及来源座位；每个候选独立构造数组，过牌基线仍用原副露。既有暗杠保留，不按四张牌误计成四张有效牌。规则、计分、明杠决策和未注入番型估值的调用不变。

血流普通 AI 通过 `claimMeldProjection` 控制；`VITE_BLOOD_FLOW_CLAIM_MELD_PROJECTION=off` 可在重新构建后回退。LLM 配置显式关闭，Python WS 实现未改。本次解决的是输入结构错误，不预先假定它一定提高牌力。

对照明确为上一版已启用 `routeOpportunityGuard` 的正式 AI，候选与对照**只差副露投影开关**。更早的评估基线固定关闭新开关，避免历史实验随生产默认值漂移。

1. 单元回归：碰、多种吃候选、已有暗杠、输入不变、候选隔离、回退。
2. 重建 `1100001-peng`、`1100008-peng`；记录真实动作，不把「修好输入」等同于「必须改成过」。
3. 使用可注入对照的四局东风场底座，核对公共前缀复用与完整重放一致，当前正式版 A/A 为零。
4. 试跑 4 个种子 1200001–1200004，仅检查接线、触发和耗时，不调参数。
5. 固定正式样本 **128 个未见种子**：1210001–1210064、1220001–1220064；每种子候选四座轮换对三个对照，积分结转、庄家轮换，共 512 场候选东风场和 128 场全对照。
6. 主指标为每座每东风场配对净分增量，按来源种子聚类 bootstrap。两臂均保留上一轮机会约束。区间跨零则只认定结构修复、不能宣称牌力提高；显著负向则停止默认推广并保留诊断／回退。披露反向损失、第一比例和大额放炮变化。

正式两批各拆为两个 32 种子的计算分片；参数和样本总数不根据中途结果调整。全部本地计算，无付费 LLM 调用。

## 结果与验收

**结论：结构错误已修复并默认启用，保留独立回退。完整对抗方向为正，但未达到预设的统计确认标准，不能宣称这项修复已证明提高牌力。** 上一轮已验证的残局机会约束继续开启。

正式 128 个来源种子全部跑完，候选四座轮换共 **512 场东风场／2048 个候选完整小局**，另有 128 场全对照／512 个控制小局。按来源种子推断，不能把四座或四局当成独立样本。四个计算分片分别约 852／901／888／883 秒，并行约 15 分钟。无付费 LLM 调用。
