# 残局大牌路线机会约束：验证协议与结果（2026-09-20）

## 冻结的单一假设

上一轮定位到：分数落后超过 300 时，大牌路线可以无视墙余门槛撤掉首胡选项；某些仅剩 3／13 张墙的局面因此拒胡并损失收益。本轮验证一个最小策略改动，不调参，不改变生产默认值。

实验策略 `first-self-draw-no-deficit-wall-bypass-v1`：

1. 只作用于未锁手、能自摸首胡的窗口（含杠上开花）。
2. 复用原有路线机会门槛：通常墙余至少 20 张；原路线口径的精牌计数达到 2 张时至少 15 张。
3. 若只有分数落后豁免让路线撤掉「胡」，则本次决策不执行路线收窄，重新交给原 EV 决策。
4. 不强制胡：原 EV 仍可选择有利的改张／杠。早中局、已锁手、点炮／抢杠窗口均不改变。不会撤销动作优先级等其他政策对胡候选的限制。

这是一条**剩余机会代理约束**，不是精确的番型完成概率模型，也不是「墙余不足就绝对做不成」的数学证明。门槛来自原配置，未根据本轮结果搜索。主要目标是平均净分，不以提高逆转第一概率为唯一目标。

## 完整对局协议（在查看试验结果前固定）

- 每个独立种子生成一个四局东风场，庄家逐局轮换，积分逐局结转；每场初始四家各 2000 分。
- 同种子的四份牌墙及骰点固定，将新策略分别放到 0／1／2／3 座，每次对抗三个原 AI；另跑全原 AI 对照。
- 候选从开局起在其全部决策窗口生效，不是只替换选中的反事实窗口。所有策略只接收本家暗手和公开信息，不读取实际对手暗手／未来牌墙。
- 主指标：候选座位每东风场净分；同时记录相同发牌下对全原 AI 的净分增量。由于全基线零和且四座全轮换，两者的种子均值必须相等。
- 辅助指标：名次、第一比例（并列第一计入）、胡次数、首胡墙余、单次弃牌批次赔付 ≥160 点的累计损失、门槛触发与实际改招次数。
- 统计独立单位是来源种子。先平均同种子四座，再作 4000 次种子 bootstrap；不能把四座／四局视为独立样本。所有未触发修改的场次仍进入主指标。
- 测试／重建案例种子与正式种子不重叠。先用 `980001–980004` 做四种子试跑，只检查正确性、触发率与耗时，不据此改候选规则。
- **正式固定预算：128 个新种子**，分为 `1000001–1000064` 与 `1010001–1010064` 两批。共 512 个候选东风场（2048 个候选完整小局），加 128 个基线东风场（512 个控制小局）。两批使用完全相同的策略和配置，不中途因结果好坏提前停测。
- 判定：正式合并的主指标 95% 区间下界 >0 才称为存在净分增强证据；区间跨 0 记为未定，整体为负则否决。两批方向、触发频率和损失尾部同时披露。即使通过，本轮也只交付验证结果，不自动开启生产默认开关。

## 精确复用公共前缀

为减少重复计算，每个座位只在候选与原 AI 第一次选出不同动作时分叉。在此之前两者状态和积分完全一致，后续候选会继续在所有窗口运行，直到四局全部结束。若整个基线东风场里该座位没有动作分歧，则候选结果与基线严格相同。

这是计算复用，不是抽样筛选；无分歧的座位仍计入对战结果。专门测试将该实现与四座从头完整重放比较，要求结算、分局分数、门槛事件、付款与首胡指标全部一致。全基线 A/A 的四座配对差必须全为 0。

## 结果

**通过本轮预设的净分验证标准：小幅且在两批未见种子上重复出现的收益。不是每场保证获利，也没有证明拿第一的概率提高。生产默认未修改。**

128 个正式来源种子全部完成，候选四座轮换共 **512 个东风场／2048 个完整小局**，另有 **128 个全基线东风场／512 个控制小局**。每场 4 局、分数结转；推断单位是 128 个来源种子，不能按 2560 个小局当成独立样本。公共前缀复用共实际计算 91,140 条动作。四个分片墙钟分别为 763.3／775.0／739.7／717.9 秒，并行运行约 13 分钟，API 请求 0。

### 主指标：每座每个四局东风场净分增量

| 批次 | 独立种子 | 候选东风场 | 平均增量 | 95% 种子 bootstrap 区间 |
|---|---:|---:|---:|---:|
| A，1000001–1000064 | 64 | 256 | **+27.50** | [+5.82, +50.55] |
| B，1010001–1010064 | 64 | 256 | **+22.52** | [+3.79, +39.26] |
| 合并 | **128** | **512** | **+25.01** | **[+10.53, +39.25]** |

合并标准误 7.22 分，正态近似区间 [+10.86, +39.16] 与 bootstrap 一致；折算每小局平均 **+6.25 分**，区间 [+2.63, +9.81]。全基线按四座平衡后的均值为 0，因此这里的候选座位净分均值与配对净分增量恰好相等。没有使用整桌绝对净分、胡牌次数或单个有利窗口代替主指标。

按来源种子先平均四座：58 个种子为正、15 个为负、55 个为零。4 种子试跑的 +71.56 分没有加入正式结果；不能用它替代正式 +25.01 分的效果量。

### 生效范围与代价

| 指标 | 结果 |
|---|---|
| 出现动作分歧的候选场次 | 110/512（21.5%） |
| 配对净分更好／更差／相同的场次 | **80 / 20 / 412**；其中 10 场虽改招但终局净分相同 |
| 门槛触发／实际改招 | 169 / 141 次 |
| 改为胡／改为其他动作 | 77 / 64 次，约束没有变成「残局强制胡」 |
| 触发路线 | 碰碰胡 161、九莲 6、混一色 1、清一色 1；本轮没有十三幺触发 |
| 平均名次变化（负值为改善） | −0.0156，区间 [−0.0293, −0.0039]，幅度很小 |
| 第一比例 | 对照 25.00% → 候选 24.80%，**少 1 次第一** |
| 第一比例配对变化 | −0.195 个百分点，bootstrap 区间 [−0.586, 0]；事件很少，不能宣称提高夺冠率或证明没有夺冠代价 |
| 大额弃牌赔付累计变化／东风场 | +0.80 分，区间 [−0.84, +2.56]，未见明确变化 |

主要证据来自碰碰胡路线；其余路线的独立样本太少，不据此宣称各路线分别获益。平均净分增强不等于提高「落后后拿第一」的概率，也不等于所有残局都应及时胡牌。

### 结论与下一步边界

本轮有证据支持：**在当前规则、当前三家本地 AI 对手、四局东风场、以平均净分为目标时，限制首胡窗口的大牌路线落后豁免有小幅净分收益。** 两批独立种子方向一致，均达到预设正区间标准；这与上一轮「还不能证明改张候选普遍优于当前 AI」不冲突，本次只改了特定路线约束。

适合将这个已验证策略作为可回退的候选选项接入下一步工程；本轮交付仍保留在 `scripts/`，不自动改生产默认或 LLM 候选层。不覆盖半庄、多名新策略 AI 同桌、真人／LLM 对手，也未验证更换番表后的表现。

若进一步优化，优先针对「双精／三精、墙余 11–14 张仍可能做成」这类负例设计牌型完成机会估计，然后使用新的未见种子验收；不要直接把本批收益外推成全面提高牌力。
