## 口径（三个指标怎么算）

**② 得分番值贡献率**（三种口径同时给出，避免"两种得分"的口径歧义）：

- **②a 得分成分贡献率**：把最终倍率按固定顺序做增量归因——`1`（基础 1 番）→ `+Σ(weight−1)`（番种番值）→ `+杠加成` → `×事件倍率` → `×硬胡×2` → `封顶截断`。恒等式：六项之和 = `finalMultiplier`；×底分 10 = 点。
- **②b 番种番值份额**：每个番种的 `Σ(weight−1)` 占全场番值的比例（"谁在真正产出番值"），以及按番值份额摊到该番种的赔付（赔付份额）。
- **②c 得分方式贡献率**：按胡牌来源（自摸 ×2 三家付 / 点炮 ×1 一家付 / 抢杠 ×2 / 杠上开花 ×4）拆出现次数、均付、番值份额与总收份额。

**③ 番种重叠矩阵**：同一次胡牌里共现的无序对 `a|b` 次数；每个番种的 `出现次数`、`独占次数`（该手牌只有这一张番）与独占率；并按"单番种胡 / 多番种胡"给出重叠率。

## 边界与说明

- 这是**分布测量**，不是对抗胜率：四席同策略自对局，只能说明"这套番表 + 这套 AI 在自博弈里长什么样"。
- 主路线是**事后归类**（按已胡手牌的番种），不是 AI 的决策路线；AI 的路线承诺（十三幺/九莲）另由 route 臂的 `routeCommits` 计数给出。
- 得分拆解的乘法归因依赖固定顺序（番值 → 杠加成 → 事件 → 硬胡 → 封顶），换顺序会改变各项份额（总和恒等于最终倍率，故份额可比、单项数值不可单独解读为"因果贡献"）。
- 番值份额按 `weight−1` 计：鸡胡（1 番）与门清平胡（兜底 body）的贡献主要体现在"基础 1 番"与出现率上，不体现在番值增量里。
