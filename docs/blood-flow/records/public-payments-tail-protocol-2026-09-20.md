# 公开特征、后续支付差与尾部价值：运行前协议

训练扫描 320001–320256，留出扫描 321001–321256；每源种子最多取第一个合格排序分歧。若任一集合不足八个窗口，仅按窗口数决定双方同增 256 个源种子；最多各 512 个，不能根据收益补样。候选和快照先冻结，旧模型、1.2 阈值、八摸定义、原墙加八个成对墙序置换保持不变。全部座位使用冻结 source-v2，窗口采样和标签不得读取新预测模型。

三个目标分开：

1. **即时支付**：单候选当前弃牌实际支付。公开风险特征包含已有风险代理、对手锁手数、桌面可见同牌数、本家持有同牌数、同花色公开副露量、最高公开风险档、弃牌类别和墙余。只使用公开信息及本家已知牌，不读取对手暗手。比较旧冻结标量 0.07705203、新训练标量、训练支付均值、零预测和新特征模型。
2. **后续支付差**：八摸内 `点炮支出 − 当前即时支付 + 其他胡牌支付` 的新旧差，避免即时成本重扣。以候选公开特征差、八摸毛收入预测差、尾部毛收入代理差、活自摸口概率差和剩余精牌数差建模。与零差预测比较。
3. **尾部净价值差**：`本局剩余净收益 − 八摸净收益` 的新旧差。只用当前窗口特征，不能使用未来第九次摸牌时才能看到的状态。比较零尾部、当前固定手牌投影的尾部毛收入差和新特征模型。

预先固定模型：标准化线性岭回归，惩罚强度 1，不做超参数搜索。即时模型有截距，预测支付下截为 0；配对差分模型无截距，以训练 RMS 缩放而不中心化，保证交换新旧候选时预测恰好反号。所有标准化参数只从训练窗口估计。后续支付和尾部使用每窗口八个墙序置换的均值训练，原墙结果单列复验。

尾部加入物理边界：墙余不超过八张，不可能再发生第九次真实自身摸牌，故尾部预测必须为零。该条件在拟合/读取留出结果前固定，不从样本误差选阈值。

组合诊断：`八摸毛收入差 − 即时预测支付差 − 后续预测支付差 + 预测尾部净差`。八摸杠净差暂取 0，遗漏项单列。组合只做冻结窗口的影子选择，不宣称整场策略提升；生产默认不改。留出结果不能用于更改特征或正则强度后重用同批验收。
