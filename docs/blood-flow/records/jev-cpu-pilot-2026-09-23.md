## 定性复盘（标记窗口，摘要）

digest 共标记：blind 高置信分歧 19、hint 13；大额赔付（≥200 点）blind 6、hint 2、baseline 11；拒胡 baseline 19、两 jev 臂各 1。三个可复述的模式：

1. **系统性偏爱鸣牌**：hint-match3 `window/10`——手牌 `m4,m5,m6,m6,p1,p3,p8,s3,s4,s8,s8,east,north`，下家打南，Jev 以 **96.3%** 概率选「吃 south-east-north」（EV 推荐过）；hint-match2 `window/110` 同类碰牌分歧 @83%。见副露即吃碰、无位置/灵活度概念。
2. **几乎从不拒胡**：1 vs baseline 19。EV 的首胡门槛（早局低番拒胡保大牌路线）Jev 完全不具备，早局即锁手吃低番。
3. **无危险概念**：blind 放炮 8.2 次/场；hint 提供安全度/风险赔付特征后**放炮次数没降**（83 vs 82），但单次赔付减半（胡付款 6555 vs 12895）——1.5B 模型能部分利用「赔多少」，利用不了「危不危险」。

边界：以上为定性观察 + 账本归因；单手是否真亏未跑反事实量化（`scripts/blood-flow-counterfactual.ts` 工具在，标记窗口清单在 digest.json 的 `matches[].flagged`，可随时补）。

## 已证明 / 未证明

- 已证明：整条「Jev 决策 → 记录 → 导出 → 摘要」流水线在真实端点上可靠；1.5B zero-shot 在本模板下显著弱于本地 EV；hint > blind 方向成立（特征描述有价值，但利用率低：一致率仅 +2.6pp）。
- 未证明：更大基座（7B/14B）的表现；LoRA 校正/蒸馏后的表现；模板 v2（criteria 短语化）对 1.5B 的可读性改善；Jev 架构（概率输出、置信路由）在上限模型下的价值。
