# 固定副露约束下的番型潜力修复（2026-09-22）

## 问题与修正

来源为7b8276db东二局窗口215、座位1。手牌已固定吃三四五万、碰八万，打四条后的候选却列出大三元、小三元、四暗刻。原局SHA-256：03eaea6df75d92d2f88deaaed2194bcdb56631c93b8be0e0c6acda153d79d788。

根因是patternPotentials对暗手对子/刻子/精牌计算接近度时，没有统一检查固定副露占用的面子位置；错误方向会进入潜力总分、发育估值和防守上限，不只是显示标签。

新增patternReachability.ts，按不可撤销的固定副露进行必要条件过滤，接入patternPotentials的统一add入口：

- 大小三元/四喜：已有对应刻/杠计入目标，剩余面子位置必须足够；小三元/小四喜还要留下不同字牌作将。
- 三/四暗刻：未固定的位置加普通暗杠，才是可达到的暗刻上限；明碰、明杠、吃和风杠不算暗刻。
- 三/四杠：已碰的牌仍允许将来补杠；吃组与风杠不能转成普通杠。
- 七对、豪华七对、十三烂、七星十三烂、十三幺、九莲：任何已声明面子都会排除这些特殊结构，包括暗杠。
- 清/混一色、绿一色、幺九类等方向必须与固定副露的实际牌面相容；已成组的精牌面不能重新替换成别的牌。
- 门清与特殊结构分开：暗杠/风杠可保门清，并不表示还能做七对或十三幺。

快速收入估算certainPatterns同样排除被固定副露阻断的番型；花色集合改为同时包含暗手自然牌与固定副露，修复“暗手是一门就把整手认成清/混一色”的错误。风杠不再被计作暗刻单位。

这里只判断固定副露导致的确定不可能。返回可行并不代表所需牌仍未打完、一定能做成或值得追；没有改变真实胡牌计分器，也没有迁移整个legacy估值体系。
