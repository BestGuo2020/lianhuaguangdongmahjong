# 血流本地 AI 贪婪 EV 策略（2026-09-07 定稿）

范围：master 前端本地 AI（非 LLM 主题座位与 LLM 回退路径）。LLM 决策提示词、计分、封顶、锁手、胡后自动续行规则一律不动；P2P / vibehub 继续后置。策略只做决策，不改任何规则状态。

## 决策框架

同一响应窗口内的可选动作全部折算成期望收益（EV），取最大者。胡不再无条件优先（多响裁决时"胡优先"是规则层的事，与 AI 自己的选择无关）。锁手后行为不变：有胡就胡、没胡摸打、窗口自动过。

### 单次胡收益（实际窗口用引擎精确分）

- `立即收益 = paymentPerPayer × 付款人数`（自摸/杠后自摸 3 家，点炮/抢杠 1 家）；`paymentPerPayer` 直接用引擎给该窗口算好的 `ownScore`，不自算。
- 封顶、硬胡、事件倍率都在引擎分里，AI 不再另算。

### 连锁期望（锁手后继续胡）

锁手后手牌冻结，后续期望只取决于听口宽度与剩余牌：

```
chainEv(hand13, melds) =
  Σ_{t ∈ waitingTiles(hand13, melds, jokers)}
      remaining(t) × avgWin(t) × chainFactor

avgWin(t) = (selfDrawWeight × 3 × paySelfEst(t) + 1 × payDiscEst(t)) / (selfDrawWeight + 1)
chainFactor = min(1, chainHorizon / max(1, wallCount / 4))
```

- `paySelfEst / payDiscEst` 用廉价估算器 `estimateWinIncome(hand13 + t, …)`：番型权重叠加 × 事件倍率 × 硬胡近似（手牌无精牌才计 ×2）× 每人封顶 64，只用于排序，不用来结算。
- 单吊任意听（`waitingTiles` 返回全部 34 种）时 chainEv 自然爆表——这就是"改张为单吊任意听"的量化依据，不需要特判。

### 首胡门槛（拒绝"见胡就胡"的快路径）

首胡锁手的代价最大。当本次支付低于当前阶段门槛、且手牌改造潜力达到 `potentialFloor` 时，拒绝本次胡（选择过 / 改张 / 其他动作），保留发育权：

| 阶段（墙余 wallCount） | 门槛（单家支付，取合法 10 的倍数档） |
|---|---|
| 早局 > 40 | 40 |
| 中局 16～40 | 20 |
| 残局 ≤ 15 | 10（= 见胡就胡，先解锁连胡资格） |

潜力不足（烂牌）时门槛不生效，见胡就胡。

### 改张（自摸窗口）

摸牌能胡时，枚举全部合法弃牌 `i ≠ 摸牌位`，计算弃后 13 张的 `chainEv + 潜力分`；存在 `改张EV ≥ 1.2 × (立即收益 + 锁手 chainEv)` 时，选改张（弃别的牌保留摸牌），否则按上面门槛决定胡或过。锁手后不适用（自动摸打）。

### 抢杠窗口（用户定稿：同样贪婪比较）

选项只有胡 / 过：

- `EV(胡) = 抢杠单家支付 + 锁手 chainEv(当前 13 张)`
- `EV(过) = −补杠杠分 + 继续发育期望（潜力分 + 已听时的 chainEv）`

贪婪取大。多数局面胡仍占优（被抢牌绝张、白付杠分、事件 ×2），但低番抢杠 vs 距任意听 / 大番只差一张时会过。锁手后不变（自动胡）。

### 吃碰杠与弃牌

- 保留 lotusAi 现有 decideTurn / decideClaim 的听口、向听、安全度框架（经典玩法零改动）。
- 血流调用时注入两个可选回调节点（默认不传，经典行为不变）：
  - `patternBonus`：番型潜力分（见下）加权进候选弃牌/碰吃质量；
  - `safetyExposure`：放炮成本 = 牌河公开张数档位（0 → 0.25 / 1 张 → 0.1 / ≥2 张 → 0）× 估算单家支付，从候选弃牌 EV 里扣除。

## 番型潜力评分

新模块 `patternPotentials`（纯函数），对 16 番型 + 特殊手输出"接近度 × 权重"：

- 清一色 / 混一色：花色集中度 + 字牌 + 精牌；碰碰胡：对 / 刻 / 精牌计数；字一色：全字牌；九莲：同花色 1112345678999 形态；绿一色：限定牌面子集；清幺九 / 混幺九：幺九与字牌刻；大小三元 / 四喜：箭风刻计数；三 / 四暗刻：暗刻计数；三 / 四杠：已声明杠计数；七对 / 十三幺 / 十三烂 / 七星沿用现有潜力函数（移入新模块供 lotusAi 共用，行为不变）。
- 目标不锁死：每摸一张重估全部方向；`patternBonus = Σ 方向 weight × progress² × 底分 × 局内系数`。
- `estimateWinIncome` 复用同一套计数做完整 14 张的快速番倍估算（封顶 64 / 人）。

## 参数默认值（集中在 config.ts）

| 参数 | 默认 | 说明 |
|---|---|---|
| `strategy` | `'ev'` | `'legacy'` 保留旧行为（`minimumFirstPayment`） |
| `selfDrawWeight` | 6 | 自摸总收入（×2 ×3 家）对点炮（×1 ×1 家）的权重 |
| `firstWinFloor` | 40 / 20 / 10 | 见上表，按墙余分段 |
| `potentialFloor` | 2 | 拒胡所需的最小改造潜力（Σ weight×progress²；2 ≈ 一个 4 倍级方向 0.7 接近度或成型方向组合） |
| `reformGainRatio` | 1.2 | 改张需 ≥1.2× 立即胡 EV |
| `chainHorizon` | 8 | 连锁期望展望巡数 |
| `safetyCostLadder` | 0.25 / 0.1 / 0 | 弃牌放炮成本（公开 0 张 / 1 张 / ≥2 张） |

贪婪最优：EV 最大者取一，平局取确定性次序（胡 > 改张 > 其他），不注入随机扰动。

## 玩家改张提示（仅自摸窗口；抢杠窗口零提示）

1. 可胡时：操作栏下方一行小字「改张：打 [牌] → 癞子单吊·任意听（后续每巡可胡）」或对应理由，仅在 `改张EV ≥ 1.2 × 立即胡EV` 时出现，每次最多一条。
2. 点"过"后：该弃牌在手牌上复用 G04 听牌箭头机制加徽标（独立样式），点击悬停仍显示原听牌网格。
3. 数据同源：提示由同一套策略函数从 `handWaits` 工作线程结果计算（waits 已带每张的自摸 / 点炮精确分），不另起一套 EV 实现；不自动替玩家执行。

## LLM 决策接入（2026-09-08 追加）

血流 LLM 座位沿用既有决策链路（preparedDecision / 条件深思 / 预算与窗口校验 / 赢家台词预合成）。本次接入：

- **候选注入同源 EV 特征（`features.ev`）**：win 候选带立即总收、锁手连锁、首胡门槛阶段与拒胡理由；自摸窗口每个弃牌候选带改张 EV（含单吊任意听标记与潜力方向）；抢杠窗口胡/过两值；过候选带发育期望。计算复用本地策略的同一份 `bloodFlowEvContext`，单一事实来源，模型不自行算分。
- **默认推荐 = 本地贪婪决策**：`engineSuggestion` 改用 `decideBloodFlowActionEv`（原为 legacy 见胡就胡）。
- **模型权限：可覆盖、要理由**（用户定稿）：system 文案明确模型可覆盖建议以表现性格与判断，覆盖时 message 必须简述理由；reasoning 走条件深思气泡。采纳时可留空短句。
- **改张候选只在自摸窗口注入**，与玩家提示口径一致；抢杠/点炮窗口不注入改张。
- **不新增请求频率与台词通道**：每窗口仍一次请求；拒胡/改张落地走普通弃牌台词；抢杠过无台词；EV 特征本地同步计算、不占用模型请求预算。
- **开关**：`BLOOD_FLOW_AI.llmEvFeatures`（默认 true）；关闭回退旧提示词与 legacy 默认推荐。

验收：新增 `bloodFlowEvFeatures.test.ts` 5 项；真实 DeepSeek 固定输入四条（改张任意听、早局拒胡、抢杠过、抢杠胡）全部选择合法且覆盖建议时给出理由，见验收页。
