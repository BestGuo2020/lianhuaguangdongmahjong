### 对本项目的直接启发

1. **先确认动作，再突出牌型，最后交代收付。** 角色负责“谁做了什么”，主番字负责“这次胡了什么”，数字负责“结果怎样”；三者通过阶段交接承担不同任务。
2. **来源与落点都能辨认。** 点炮时先看到供牌位置，再看到赢家楼位的落牌强调。光柱与粒子为牌的动作服务，不能只在固定角落持续发光。暂不制作手模型时，也要保留取牌、移动、落牌、整理等可见阶段。
3. **多响按一个来源、多个赢家组织。** 共享提示可结合来源位置，各赢家在自己的席位展示动作和主番。立绘可以同阶段分席出现，但共享标题与它们错峰，避免当前三响主字被顶部角色遮住。
4. **字效强调轮廓、厚度和快慢差。** 参考中的字有笔画造型、大小字组合、暗侧边和透视；不是只把普通字体整体放大。五主题保留各自配色，借鉴层次与运动，不全改为金字。
5. **日常牌桌留给打牌。** 胡次数与头像关联，楼牌直接展示积累；胡牌时突出主番和收付，不反复列整套付款说明。这里的表达不依赖我们的五行赢家卡。
6. **有阅读停留，也有短促重拍。** 不能根据这段视频的总长度、倒计时数字或某次玩家等待直接设定项目节奏；应分别校准普通摸打、响应、命中、读番、收付和下个操作的开放时机。

保留用户已确定的边界：局内胡牌无自由感言，原动作报声和角色音色路由复用；普通 LLM 动作气泡按原主题和频率设置；全桌感言只在本局结束后、仅 llm / llmAnime。视频中有的角色或语音表现不自动成为新的台词、TTS 或资源需求。

## 3. 打击感来自哪些具体手法

### 3.1 强烈的快慢差与大小差

视频标题不是常规的从 80% 缩放到 100%。1:18.8 的字明显大于最终停留尺寸，随后迅速缩回；爆发帧和可读帧承担不同任务。大字有斜角、描边、明暗层次，字形本身就是视觉主体，不需要大面积矩形容器。

可借鉴：标题短时间越过最终尺寸再收稳，配合少量位移和角度变化。不能只延长播放时间或增加粒子数量，期待产生同样的重量感。

### 3.2 背景先退，主效果才显得亮

本家大胡时桌面整体压暗，主标题及落点局部很亮；其他阶段桌面恢复。亮暗对比集中在关键瞬间。

可借鉴：本家大番或顶级番短时压暗环境，局部强调胡牌张与标题；其他人普通胡只做席位区域强调。不要每次都全屏变暗，更不要持续闪白。

### 3.3 有方向的落点，而非单纯持续发光

光束指向具体牌位，环形高光和后续变化都围绕落点发生。玩家能理解“牌到了这里”。手部模型也强化了牌被拿取 / 放下的过程。

可借鉴：先实现真实胡牌张从来源到自己楼层的短轨迹和落层回弹，不必第一阶段就制作真人手模型。抢杠从对应杠位来，点炮从弃牌位来，自摸从本次摸牌位来。

### 3.4 获益与付出同时可见

1:20.6～1:21 的赢家正分和三家负分分布在四个席位方向；3:19 附近他家胡牌也同时给出一正一负。文字较大、颜色区分明确，容易看清一次事件的影响。

可借鉴：我们的每个批次已经有四家 delta，应该同时驱动赢家正分和付款者负分。金额用项目真实积分，不通过放大数值或仿制金币经济制造效果。

### 3.5 本家和他家的演出位置不同

本家大胡使用中下方较大的焦点区；3:16～3:19 的右家清一色主要在右侧席位附近出现。对局中的重要事件不会全部抢占同一个中央位置。

可借鉴：本家大胡用主舞台，他家用席位舞台。一炮多响中央只讲“几响”，各赢家各自显示番型，分别收分。不能只展示最强那家的番型而让其他赢家失去身份。

### 3.6 音轨也存在分段的重拍

混合音轨在 1:18.7～1:19.3 的平均 RMS 约 0.142，而前段 1:14～1:17.4 约 0.023；1:20.56 附近又出现约 0.202 的局部能量峰，与大号分数出现阶段接近。基准前段也包含较高的单次峰，不能据此断言所有声音都在大胡阶段更响。

这支持“声音能量集中在几个关键阶段”的时序观察，不证明具体用了什么音效，也不能从录制视频断言游戏程序用了暂停帧、时间缩放或镜头震动实现。

可借鉴：保持已有胡 / 自摸等动作报声不变，若补打击音，使用独立的非人声效果通道，优先复用已有胡牌效果音。让落点、标题重拍和效果音对齐，避免同一批次由多个入口重复播放。无需新增局内 LLM 感言。

## 5. 建议的本项目大番时间安排

以下为首测建议，不是视频测得的参数。以视觉批次开始为 0ms，原动作报声仍由现有入口触发。

| 时间 | 建议表现 |
|---|---|
| 0～100ms | 胡牌来源高亮，轻压暗非焦点区域；主番预备入场 |
| 100～220ms | 胡牌张快速飞向目标层；牌型字到达超出最终尺寸的重拍；落点闪光与独立效果音对齐 |
| 220～450ms | 牌轻弹落稳；标题回到稳定尺寸，显示硬胡、自摸及组合倍率 |
| 450～800ms | 四家正负分同时弹出，各自靠近席位；楼层次数明确增加，标题保留可读性 |
| 800～1200ms | 主字效退出，光效收束，保留楼牌、分数和流水入口 |

顶级番型可延长阅读 / 收势至约 1500ms；普通胡与短时间重复胡压缩到约 400～650ms，重点保留一次明确落点和一次收付反馈，不每次完整播放大场面。

可试的标题运动：小尺寸快速入场 → 1.3～1.4 倍过冲 → 约 0.96 回弹 → 1.0 停留。冲击帧较短，停留帧更长。不同主题改变字形、描边、配色和轨迹，不从“莲花”地名推导图案。

原 450ms 权威动作节拍不为追求爽感而任意拉长；后续表现放在不挡手牌和操作的席位区域。积分先按规则提交，显示动画不能延迟或再次执行收付。不能直接照搬参考中约三秒多的一整段演出到每一次连续胡牌。

## 6. 优先实施的四项

1. **统一表现时间安排**：一个 cue 对应一个批次 ID，字、3D、落楼、正负分、非人声效果音共同消费同一开始时间和关键节点；动作报声继续走既有出口。
2. **先补牌和字的动作**：来源 → 楼层的飞入落地，以及标题过冲回弹。即使粒子不增加，这两项也能明显改变运动结构。
3. **补四家收付重拍**：从 batch.deltas 生成正负分，同时标明受影响席位。当前得分账保持权威值，动画不产生新收付。
4. **再做强弱与视角差异**：本家顶级番完整舞台，他家席位舞台，重复胡紧凑版，多响统一批次；最后调整局部闪光、背景压暗和可选轻震。

验收取同一固定事件，比较普通胡 / 硬胡大番 / 十三幺封顶 / 连续十胡 / 一炮三响；检查是否能一眼读出“谁胡、胡什么、谁付、牌落哪里”，再评价冲击是否过强或拖沓。

## 7. 不改变的边界

- 现有动作报声代码、资源和角色音色不重写，不另做“我胡了”语音，不双播。
- 局内没有赢家感言、付款者感言或全桌评论；全桌感言仍只在本局结束后、仅两个 LLM 主题启用。
- 持续盖楼不改回收纳上限；只补新牌落层的运动和对应提示。
- 不修改底分、番型倍率、胡牌概率或 P2P 收付规则来模拟视频中的大金额。
- 不必制作参考中的所有手部模型、角色、金币素材或复制其 UI；五主题使用项目自身视觉来源。
