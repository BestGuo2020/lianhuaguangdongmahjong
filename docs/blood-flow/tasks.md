## 当前推进顺序

本阶段遵循用户最新顺序，不另建计划：

1. **普通动作：已实施并核对。** 落牌 → 响应，吃碰成组 → 出牌，杠成组 → 补牌 → 出牌；正常大厅实玩及固定输入补验有连续帧。
2. **胡牌节奏：已实施并核对。** 来源停留、飞行、命中回弹、读番、收付连续展示，再交回操作；重复推进不能再次计分或摸牌。
3. **基础反馈：已恢复并核对。** 普通胡保留可见光柱、粒子与落点反馈，高番在此基础上增加差异；五主题保留原风格。
4. **实玩：本阶段已完成。** 正常速度东一局，四家胡 10 / 11 / 2 / 0 次；实玩自然触发吃、杠、二响、重复胡、跨层和结算返回。高番与三响另有场景补验。声音未实听，见[本轮证据](acceptance.md#2026-09-05-master-单机可玩性复修)。
